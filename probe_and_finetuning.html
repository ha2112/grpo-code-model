Difficulty probe and fine-tuning setup

A compact summary of the current experiment.

1. Probe data and results

The probe is trained on the train split of deepmind/code_contests. It keeps only Codeforces examples (source == 2) with a positive cf_rating, giving 7,701 rated problems in the current result CSV. The problem description is formatted with the Qwen chat template and passed through a frozen Qwen2.5-1.5B-Instruct model. The feature is the final-layer hidden state at the last input token (1,536 values); a single linear layer predicts the Codeforces rating.

The data split is approximately 64% train, 16% validation, and 20% test (seed 42). Feature and target scaling are fit without the test set, then folded into the saved probe so inference uses raw embeddings.

2. Current fine-tuning setup

Training method: Group Relative Policy Optimization (GRPO), launched with grpo/afterburner_train.sh in the Afterburner project.
Training dataElfsong/Venus_Python; train and test parquet files are built from Python competitive-programming problems.
TasksImprove an original solution for time, memory, or combined time/memory efficiency. The three task variants are concatenated.
Policy modelElfsong/Qwen2.5-Coder-3B-Venus-Cold-Start
OutputOne <thinking>...</thinking><solution>...</solution> response containing the complete code.
Reward50% improvement/correctness reward and 20% format reward in the final combination; the configured length component is currently zero. Correct solutions can also receive an efficiency improvement reward.
EvaluationGenerated code is executed against tests through the Monolith endpoint; failures/timeouts receive poor performance scores.
Main settingsGRPO batch size 32, 32 generations, learning rate 1e-6, response limit 8,192 tokens, tensor parallel size 2, 8 GPUs, 200 epochs, checkpoint/test every 10 steps.

The difficulty probe is not currently a reward in this Afterburner setup; it is a separate analysis tool. The authoritative implementation is in train_codecontests_probe.py and the fine-tuning launcher is in ../Afterburner/grpo/afterburner_train.sh.
